# Rules for Claude Code in this repository

- Add no attribution anywhere: no `Co-Authored-By` trailers, no session-id trailers or claude.ai session links, and no "generated by" lines in commit messages, PR titles, PR descriptions or comments. (`.claude/settings.json` turns the built-in lines off; this rule covers the cases a setting cannot.)
- Never print, log or commit `NOTION_TOKEN` or `NOTION_FEED_DATA_SOURCE_ID`, or any Notion page or database ID. Both values come from the environment (GitHub Actions secrets).
- Keep personal data out of the repo: no email, phone, address, resume text or workspace-specific names beyond what `skills.yaml` already holds.
